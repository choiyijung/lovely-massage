핵심 원칙:
1. 지역명만 바꾼 동일 본문을 만들지 않음
2. 상위 지역 → 생활권 → 세부 콘텐츠로 계층화
3. 실제 공개 지역정보를 바탕으로 각 문서의 주제가 다름
4. 업체 카드보다 지역 설명·이동 기준·FAQ를 먼저 제공
5. 긴 키워드 나열형 URL은 따라하지 않고 짧고 읽기 쉬운 URL 사용
6. 현재 업체명/가격은 DEMO임을 페이지에서 명시
